Documentação do Script prod_final.py

Visão Geral:
Este script automatiza o processo de busca e reenvio de produtos para uma API de integração, utilizando uma lista de SKUs. Ele realiza operações de GET e PUT para buscar produtos e reenviá-los, tratando produtos simples e configuráveis (com variações/filhos). O script também gera logs detalhados de todas as operações realizadas.

Estrutura do Script:

1. Configurações Iniciais:
   - BASE_URL: URL base da API de produtos.
   - TOKEN: Token de autenticação (deve ser substituído pelo valor real).
   - HEADERS: Cabeçalhos HTTP padrão para autenticação e tipo de conteúdo.
   - ENTITY_INTEGRATOR_ID: ID do integrador da entidade.
   - REQUEST_DELAY: Tempo de espera entre requisições (em segundos).
   - MAX_RETRIES: Número máximo de tentativas em caso de falha.
   - SKUS: Lista de SKUs a serem processados.
   - LOG_FILE: Nome do arquivo de log gerado automaticamente com data/hora.

2. Funções Principais:
   - buscar_produto(sku): Busca um produto na API pelo SKU informado. Retorna o produto encontrado ou None caso não encontre.
   - resend_produto(product_id, sku=None, tipo=None): Reenvia (PUT) o produto para a API, podendo ser produto pai ou filho. Tenta até o número máximo de tentativas definido.
   - processar_variacoes(produto_pai): Processa as variações (filhos) de um produto configurável, reenviando cada um deles.
   - main(): Função principal que executa o processamento de todos os SKUs da lista, realizando busca, reenvio e tratamento de produtos configuráveis.

Fluxo de Execução:
O script inicia e configura o logging. Para cada SKU na lista, busca o produto na API. Se encontrado, faz o reenvio do produto pai. Se o produto for do tipo "configurable", processa e reenvia todos os filhos (variações). Aguarda o tempo definido entre as requisições. Todos os eventos, erros e sucessos são registrados no arquivo de log e no console.

Observações:
O TOKEN deve ser preenchido com um valor válido para autenticação. O script pode ser adaptado para diferentes listas de SKUs ou parâmetros de integração. O arquivo de log gerado facilita a auditoria e o diagnóstico de problemas.

Exemplo de Uso:
Edite o arquivo e insira o seu TOKEN. Execute o script com o comando: python prod_final.py. Verifique o arquivo de log gerado para acompanhar o processamento.
