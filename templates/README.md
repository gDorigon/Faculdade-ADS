# Templates do Obsidian

Esta pasta contém modelos para organizar as anotações da faculdade.

## Configuração

1. Abra este repositório como um cofre no Obsidian.
2. Acesse **Configurações → Plugins nativos → Templates**.
3. Ative o plugin e escolha `templates` como a pasta de templates.
4. Em uma nota, use o comando **Templates: Inserir template**.

## Modelos disponíveis

- `disciplina.md`: página inicial de uma disciplina.
- `nota-de-aula.md`: registro de uma aula.
- `exercicio.md`: resolução de exercício ou lista.
- `trabalho.md`: planejamento e acompanhamento de trabalho.
- `avaliacao.md`: preparação para prova ou avaliação.
- `revisao.md`: revisão periódica de uma disciplina.

Os campos `{{title}}`, `{{date}}` e `{{time}}` são preenchidos pelo Obsidian.
